Task 3 These are all the things required for the web page:

  1. Text:
    1. Headers
    2. Paragraphs
    3. Bold/italic etc. fonts (using <em> etc.)
    4. Special characters
  2. Graphics:
    1. Placing on the site in natural size and modified
    2. Each graphic should have alternative text (alt)
  3. Lists (bullets):
    1. Numbered and unnumbered
    2. List nesting
    3. Definition list
  4. Tables (with headers, body and footer):
    1. Standard
    2. Combining columns and rows.
  5. References (links):
    1. To another page (yours and others)
    2. To the identifier in your page
  6. Form:
    1. Several text fields (input type = "text")
    2. A drop-down list with options grouped
    3. Group of single-select items (radio)
    4. A group of multiple-selection items (checkbox)
    5. Text field for entering a maximum of 200 characters (text area)
    6. Buttons for clearing and submitting the form.
