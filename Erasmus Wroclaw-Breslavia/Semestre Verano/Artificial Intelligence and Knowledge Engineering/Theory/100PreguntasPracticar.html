Problem Solving by Searching

10 Questions
📝Search algorithms: BFS, DFS, A*, IDA*, SMA*, local search
1. Which of the following statements about BFS are correct?
AIt explores nodes level by level and is complete if the state space is finite.
BIts memory usage is O(b^d), making it inefficient for large spaces.
CIt is optimal when all step costs are equal.
DIt never visits the same state more than once in any implementation.
✅ Correct answer: B) Its memory usage is O(b^d), making it inefficient for large spaces.
2. Which properties distinguish DFS from BFS?
MULTI
ADFS is not complete in infinite search spaces or those with cycles.
BDFS expands the deepest nodes in the search tree first.
CDFS has memory usage of O(b·m), much lower than BFS.
DDFS guarantees finding the optimal solution if costs are uniform.
✅ Correct answers: B, C
3. Which of the following statements about A* are correct?
MULTI

CA* expands the node with the lowest f(n) = g(n) + h(n).
DA* is optimal if the heuristic is admissible, i.e., it never overestimates the true cost.
✅ Correct answers: C, D
4. What advantages does Iterative Deepening DFS (ID-DFS) offer over BFS and DFS?
MULTI
AIt eliminates the cost of re-expanding nodes visited in previous iterations.
BIts memory usage is O(b·d), comparable to standard DFS.
CIt combines the completeness and optimality of BFS with the low memory usage of DFS.
DIt is preferable to A* when no admissible heuristic is available.
✅ Correct answers: B, C, D
5. About local search (Hill Climbing), which of these statements are true?
MULTI

DTabu search maintains a list of visited states to avoid revisiting them.

DAdmissibility guarantees that A* finds the lowest-cost solution.
✅ Correct answer: B) A heuristic that always returns 0 is admissible but not very informative.
8. Which of these statements about IDA* are true?
MULTI

9. Which statements about SMA* are correct?

✅ Correct answer: C) When forgetting a node, SMA* stores its cost in the ancestor node for possible recovery.
10. Can any problem be formulated as a state space search?
ANo, because some problems have an infinite branching factor and cannot be represented.
