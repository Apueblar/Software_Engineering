01 🔍

Problem Solving by Searching

Foundational
Summary
A search problem is defined by: an initial state, a set of operators (actions), a goal test, and a path cost. Every problem can be formulated as state-space search — complex operations become combinations of simpler operators. The key distinction is between uninformed (blind) and informed (heuristic) strategies.
🧭 Uninformed Search
  • BFS — level by level; complete & optimal (uniform cost); memory O(bd)
  • DFS — depth first; low memory O(bm); not optimal, incomplete in ∞ spaces
  • Uniform Cost Search — expands cheapest node; optimal if step cost > 0
  • ID-DFS — iterative deepening; combines DFS memory + BFS completeness; optimal for uniform costs
✨ Informed (Heuristic) Search
  • h(n) — estimated cost from node n to goal
  • Greedy Best-First — lowest h(n); fast but not optimal
  • A* — f(n) = g(n) + h(n); optimal & complete if h admissible
  • IDA* — A* with iterative deepening; memory-efficient; re-expands states
  • SMA* — uses bounded memory; forgets shallowest highest-cost leaves
🎯 Admissible heuristic: never overestimates the true cost — this guarantees A* optimality. It "does not hide the problem." Example: straight-line distance for route finding is admissible.
⛰ Local Search (path doesn't matter)
  • Hill Climbing — move to neighbour with lowest loss; gets stuck in local optima
  • Tabu Search — allows worsening moves; maintains tabu list of visited states
  • Simulated Annealing — probabilistically accepts worse moves; probability decreases over time
⚠ IDA* drawback: re-expands already visited states (no memory of them). Trade-off for low memory usage.

Game Playing (Adversarial Search)

Adversarial
Summary
Game playing is a structured conflict where each player maximises their own payoff. The game tree models all possible moves. Min-Max assumes optimal opponent play. Alpha-Beta pruning eliminates branches that would never be chosen, halving the effective search depth. The evaluation function must be consistent with the payoff at terminal nodes.
🎮 Game Types
  • Zero-sum — one's win = other's loss (chess, Go)
  • Non-zero-sum — prisoner's dilemma
  • Deterministic — chess; Stochastic — poker
  • Perfect info — chess; Imperfect — poker
⚡ Alpha-Beta Pruning
  • α (alpha) — best value MAX can guarantee so far (lower bound)
  • β (beta) — best value MIN can guarantee so far (upper bound)
  • Prune branch if α ≥ β
  • Optimistic complexity: O(bd/2) — doubles effective depth
  • Node ordering is critical for efficiency
Key Concepts — Game Playing
Evaluation FunctionMust agree with payoff at terminal nodes and estimate it for all intermediate states. Often a linear combination of features.
Horizon ProblemStopping search before board conditions change dramatically. The algorithm returns a misleadingly calm evaluation just before a major capture.
Quiescent PositionsStates where the evaluation function is unlikely to change significantly in the next few moves — safe to stop search here.
Deep Blue (1997)Defeated Kasparov using α-β Min-Max + 8,000 patterns + opening book (4,000 positions) + 700,000-game database.
03 🔗

Constraint Satisfaction Problems (CSP)

Core
Summary
A CSP is defined by Variables X, Domains D (possible values per variable), and Constraints (restrictions on combinations). A solution is a complete, consistent assignment. Constraint propagation dynamically reduces domain sizes, making it the key to CSP efficiency.
🔄 Arc Consistency (AC-3)
  • For every arc (Xᵢ, Xⱼ): every value in Dᵢ has ≥1 compatible value in Dⱼ
  • If a value is deleted from Dᵢ, all arcs pointing to Xᵢ must be re-checked
  • MAC — maintains arc consistency after each assignment during search
  • Arc consistency = 2-consistency; path consistency = 3-consistency
🧠 CSP Heuristics
  • MRV — minimum remaining values; most constrained variable first
  • Degree Heuristic — variable in most constraints on remaining vars
  • Least Constraining Value — value ruling out fewest neighbours
  • Forward Checking — after assigning X, remove inconsistent values from others
🎯 Key exam answer: Constraint propagation dynamically reduces the effective size of variable domains. It is not an alternative to backtracking — it runs alongside it.
🌳 Problem Structure
  • Tree-structured CSPs — solvable in O(nd²), linear in number of variables
  • General graphs can be reduced to trees by removing or collapsing nodes
  • Backtracking — assign one variable at a time, backtrack on constraint violation

Planning & STRIPS

Symbolic AI
Summary
Planning = searching for a sequence of actions to go from an initial state to a goal state. Planning algorithms differ from pure heuristic search because they exploit knowledge from the symbolic representation of operators (preconditions, effects). STRIPS uses a closed-world assumption; ADL is more expressive.
STRIPS Action = Name + Preconditions + ADD list + DELETE list
STRIPSPositive literals only, closed-world (unlisted = false), goal = ground literals & conjunctions, no conditional effects
ADLPositive & negative literals, open world, quantified goals, conditional effects, typed variables
PDDLStandard language for planning systems; defines domains (predicates, actions) and problems (objects, init, goal)
🔀 Partial Order Planning (POP)
  • Least commitment principle — only order steps when necessary
  • Causal links: Sᵢ → Sⱼ (Sᵢ achieves condition c needed by Sⱼ)
  • Threats (clobbering) — action C deletes a needed condition
  • Resolve threats via demotion (C before achiever) or promotion (C after consumer)
📐 Planning Heuristics
  • Delete relaxation — ignore delete effects; use relaxed plan length
  • Landmarks — facts/actions that must occur in every solution
  • Abstraction — merge states to simplify the problem
  • FF (fast forward), LAMA, Fast Downward (A*, optimal)
🎯 Exam key: Partial Order Planning uses only the necessary ordering constraints (least commitment). Planning differs from heuristic search by utilizing knowledge from the symbolic representation of state-change operators.
05 🧮

Logical Inference & Knowledge Representation

Logic
Summary
AI uses three inference types: deduction (general→specific, sound), induction (specific→general, basis of ML), and abduction (probable causes). Deductive methods remain relevant as sources of verified knowledge for LLMs. FOL extends propositional logic with predicates and quantifiers.
📐 Propositional Logic
  • p → q ≡ ¬p ∨ q
  • False only when p=T, q=F
  • Modus Ponens: (p→q) ∧ p → q
  • Forward chaining: data-driven
  • Backward chaining: goal-driven
🔬 First-Order Logic (FOL)
  • Constants, Variables, Functions
  • Predicates: IsOpen(CB, Line4)
  • ∀ (for all), ∃ (there exists)
  • Resolution: add ¬goal, convert to CNF, resolve to empty clause
  • Unification: binding variables to match terms
🕸 Knowledge Representation
  • Semantic networks — labelled digraph; is_a, instance relations
  • <Object, Attribute, Value> triples
  • Ontologies — formal shared conceptualisations
  • RDF graphs — DBpedia, Freebase
  • Non-monotonic logic — allows belief revision
🎯 Exam key: Deductive AI is still relevant — deductive methods encode verified knowledge and can be integrated with LLMs (e.g., LINC — neurosymbolic theorem proving). Classical logic is monotonic; new facts never retract old conclusions.
06 🌳

Introduction to ML & Decision Trees

Supervised ML
Summary
A system learns from experience E on tasks T, measured by P, if performance on T improves with E. Decision trees induct attribute tests via information gain (entropy reduction). The order of attributes root-to-leaf reflects the reduction of uncertainty. Continuous attributes need statistical quantization into intervals.
📊 ID3 / C4.5 Algorithm
  • Entropy: H(S) = −Σ pᵢ log₂(pᵢ)
  • Info Gain: IG(S,A) = H(S) − Σ (|Sᵥ|/|S|)·H(Sᵥ)
  • Gain Ratio (C4.5) = IG / SplitInfo — corrects bias toward many-valued attributes
  • C4.5 also handles continuous attributes, missing values, post-pruning
⚠ Overfitting Prevention
  • Early stopping — stop before perfect training fit
  • Post-pruning — build full tree, then prune (reduced-error pruning)
  • Chi-square test — stop if further splits only help training
  • MDL — stop when encoding is minimal
  • Training ↑ with depth; test ↓ after a point
🎯 Exam keys: Attribute order in each root-to-leaf path = reduction of uncertainty. To handle numerical values: quantize (bin) them statistically per attribute from training data. Decision trees are self-explainable — rare in ML.
📐 Evaluation
  • k-fold Cross-Validation — split into k folds; train on k-1, test on 1; average k results
  • Training / Dev (tuning) / Test sets — test set kept hidden during all training
  • Inductive Learning Hypothesis — good fit on large training set ≈ good generalisation
07 🔵

Case-Based Reasoning & Unsupervised Learning

Instance-Based
Summary
k-NN classifies by finding k nearest neighbours in training data — it allows making assumptions about selected properties of unknown objects based on a similarity measure. Unsupervised learning explores similarities to determine equivalence classes (clusters) without labels. k-NN is for supervised inference; k-Means is for discovering groups.
👥 k-Nearest Neighbours (k-NN)
  • Find k nearest neighbours, assign most frequent class
  • k should be odd to avoid ties
  • Euclidean: d(x,y) = √Σ(xᵢ−yᵢ)²
  • Weighted k-NN: wᵢ = 1/dᵢ (closer = higher weight)
  • Normalise attributes to [0,1] — scale differences distort distances
  • Curse of dimensionality — data needed grows exponentially with attributes
🔵 k-Means Clustering
  • 1. Initialise k centroids randomly
  • 2. Assign each example to nearest centroid
  • 3. Recalculate centroids (average of members)
  • 4. Repeat until stable
  • Sensitive to initialisation; k must be chosen
  • Internal evaluation: Silhouette, Dunn index
  • Hierarchical: dendrogram; merge closest clusters iteratively
🎯 Exam key: k-NN allows making assumptions about the selected properties of unknown objects based on a similarity measure. It does NOT discover the number of classes (that's k-Means). Unsupervised learning explores similarities to determine equivalence classes.

Naïve Bayes & Statistical Classification

Statistical ML
Summary
Bayes' Theorem: P(h|D) = P(D|h)·P(h) / P(D). Naïve Bayes assumes conditional independence of features given the class. Despite violated independence in practice, classification decisions are usually correct — because we only compare ratios, not estimate absolute probabilities.
📐 Naïve Bayes Classifier
  • P(cⱼ|D) ∝ P(cⱼ) · Π P(xᵢ|cⱼ)
  • Multivariate Binomial — word present/absent
  • Multinomial — word frequencies; generally better
  • Laplace smoothing: P(xᵢ|cⱼ) = (count + 1) / (count(cⱼ) + |V|)
  • Avoids zero probabilities for unseen words
🔤 Language Models
  • Unigram: P(string) = Π P(word) — simple, effective
  • Bigram/n-gram: P(wᵢ | wᵢ₋₁,…,wᵢ₋ₙ₊₁) — captures word order
  • MI — mutual information: association between term and category
  • χ² — chi-square: statistical significance of association
  • Feature selection on full data (incl. test) = information leak!
⚠ NB posterior probabilities are numerically unreliable (very close to 0 or 1) due to violated independence — but classification decisions are usually correct since we only compare P(A,c₁) vs P(A,c₂).
09 🧠

Neural Networks & Deep Learning

Deep Learning
Summary
Training modifies connection weights via backpropagation (chain rule + gradient descent). Activation functions shape signals layer by layer; the output layer interprets them for the task (e.g., softmax for classification). Dropout is the standard regularization technique improving generalisation. CNNs use spatially shared weights for hierarchical image feature extraction.
⚡ MLP & Backpropagation
  • z = Σ wᵢxᵢ + b, then apply activation f(z)
  • Activations: sigmoid, tanh, ReLU max(0,z), softmax
  • Forward pass → compute loss → backward pass (chain rule) → update w ← w − η∇E
  • Training changes weights; some may be suppressed entirely
🛡 Overfitting Solutions
  • Dropout — randomly disable subset of neurons each iteration
  • Early stopping — monitor dev set error
  • L1/L2 regularisation
  • Data augmentation / more training data
  • Deeper nets need fewer neurons per layer
Architectures
CNNSpatially shared weights detect local patterns. Hierarchy: edges → shapes → objects. Best for image/shape recognition. Spatially shared weights allow ignoring irrelevant pixels.
RNN / LSTMProcess sequences. LSTM avoids vanishing gradient with gating mechanisms.
TransformerSelf-attention: Attention(Q,K,V) = softmax(QKᵀ/√dₖ)·V. Parallel sequence processing. Replaced RNNs.
BERTEncoder-only, bidirectional. Pre-trained with MLM + NSP. Fine-tuned for downstream tasks.
GPTDecoder-only, unidirectional (causal masking). Autoregressive — generates one token at a time.
🎯 Exam key: For shape recognition → CNN because (a) spatially shared weights allow ignoring irrelevant pixels, and (b) hierarchical feature extraction in successive layers. Dropout = randomly disabling a subset of neurons each training iteration.
10 🎮

Reinforcement Learning

RL
Summary
An agent learns to maximise cumulative reward by interacting with an environment via trial-and-error with delayed rewards. No explicit teacher — only a reward signal. Unlike supervised ML, feedback is delayed, data is sequential, and the agent's actions affect future data.
📐 RL Elements
  • Policy π — mapping states → actions
  • Reward function — state → scalar; property of environment
  • Value function V(s) — expected cumulative future reward from s
  • Model (optional) — agent's internal env representation
  • Discounted return: Gₜ = rₜ₊₁ + γrₜ₊₂ + γ²rₜ₊₃ + …
⚡ TD Learning & Q-Learning
  • TD update: V(s) ← V(s) + α[V(s') − V(s)]
  • Based on difference between estimates at two time steps
  • Q-Learning — learns Q(s,a); off-policy; converges to optimal policy
  • ε-greedy: greedy with prob 1-ε; random with prob ε
  • γ=0: immediate reward only; γ=1: fully far-sighted
🎯 RL vs Dynamic Programming: DP requires complete model (all transition probabilities). RL learns from experience when model is unknown. Q-Learning converges if each state-action pair is visited infinitely often and learning rate decreases appropriately.

Large Language Models & Prompt Engineering

LLMs
Summary
LLMs are very large decoder-only autoregressive models (1B–hundreds of B parameters) pre-trained on next-token prediction. The pipeline: pre-training (unsupervised) → fine-tuning (SFT, instruction-following) → alignment (RLHF/DPO). For task-specific quality drops, the fix is to extend fine-tuning instructions and redo alignment.
🔧 Training Pipeline
  • Pre-training — next-token prediction; negative log-likelihood loss
  • SFT — instruction → model → output R̂; compared to reference R
  • RLHF — human rankings → reward model → RL policy update
  • DPO/KTO — alternative alignment methods
✍ Prompting Strategies
  • Zero-Shot — instruction + data, no examples
  • Few-Shot — instruction + examples + data
  • Chain-of-Thought — step-by-step examples; forces reasoning
  • Role-playing — assume a persona
  • Least-to-Most — decompose into subproblems
  • Self-consistency — model critiques its own outputs
🔍 RAG System
  • Query → retrieve relevant document chunks → LLM → answer
  • Segmentation — determines detail/granularity of retrieved context
  • Two-phase retrieval: fast first-stage (embeddings) + expensive re-ranking
  • Re-ranking maximises accuracy while minimising computation
LLM API Parameters
TemperatureLower = more deterministic/repeatable output
Top-p (nucleus)Limits token selection to top cumulative probability mass
Max lengthMaximum tokens to generate
Stop sequenceStops generation when pattern occurs
Freq/presence penaltyReduce word repetition
🎯 Exam key: If LLM shows reduced quality on certain tasks → extend instruction fine-tuning set and repeat the alignment phase (not re-do full pre-training). RAG segmentation determines the detail of the response by defining the text window size.
12 🤖

Semantic Retrieval, RAG & LLM-Based Agents

Agents & RAG
Summary
Prompting does not change the model — it only steers how the model's existing parametric knowledge is expressed. Semantic retrieval produces a ranked document list via a query-document matching pipeline. RAG grounds LLM answers in retrieved chunks, reducing hallucinations and extending knowledge beyond the training cutoff. An LLM-based agent adds memory, tools, and planning around the model to act autonomously in an environment.
🌍 Types of Environments
  • Observable — agent can fully perceive the current state
  • Deterministic — actions have predictable outcomes
  • Sequential — decisions affect future states
  • Static — environment does not change while agent deliberates
  • Discrete — finite set of percepts/actions
  • Single-agent vs Multi-agent — one or many acting entities
📊 Retrieval Ranking
  • BM25 — lexical baseline; TF-IDF + length norm; fast
  • Bi-encoder — separate query/doc embeddings; scalable
  • Cross-encoder (monoBERT) — joint attention [CLS]; most accurate, slow
  • ColBERT — late interaction MaxSim; balances speed & quality
  • Metrics: Precision@k, Recall@k, MRR, nDCG
  • Two-phase: fast retrieval (BM25/bi-encoder) → expensive re-ranking
🔗 Agent Architecture
  • Environment — decision space (OS, code interpreter, web, etc.)
  • Memory — short-term (prompt context) vs long-term (vector store, DB)
  • Tools — function calling; agent receives JSON schema, calls APIs
  • Planning: ReAct (Thought→Action→Observation loop)
  • Reflexion — generate → self-critique → refine cycle
  • ToRA — CoT + executable code (SymPy) for maths tasks
RAG Pipeline Variants
VariantWhat it adds
Naive RAGFixed: query → retrieve → generate; no pre/post processing
Advanced RAGPre: query rewriting, routing, expansion · Post: re-ranking, summarisation, fusion
Iterative RAGRetrieve → generate → judge → repeat to build up context
Recursive RAGQuery decomposition between retrieve-generate cycles
Adaptive RAGJudges whether retrieval is needed at each step (special tokens/thresholds)
🎯 Exam keys: Prompting does NOT modify model weights — it only affects how the model uses its existing knowledge. Environment characteristics: observable, deterministic, sequential, static, discrete (same taxonomy as Lecture 1 search environments). Cross-encoder > ColBERT > bi-encoder in accuracy; opposite order in retrieval speed. Short-term memory lives in the prompt context; long-term memory persists in external storage across sessions.

Real 2025 Questions
📝 Exam 2025 — All Questions (English)
Q1. Can we effectively formulate every problem as a state space search problem?
a) No, because we will have too many operators and too high a branching factor in the search graph.
b) No, because not all problems allow us to define inverse transition operators between states.
c) Yes, because complex operations can be represented as a combination of simpler operators.
d) Yes, because symbolic-arithmetic operations can be represented as operators acting on a computational graph.
✅ Answer: c) — Complex operations can be represented as combinations of simpler operators, making state space formulation universally applicable.
Q2. Is there a place for a deduction-based approach in contemporary AI?
a) No, because practically all contemporary AI systems are based on machine learning.
b) Yes, deductive methods allow for the expression of verified knowledge, e.g., in the form of rules, also as sources of knowledge for generative language models (LLMs).
c) Yes, because deductive methods are essential for data augmentation.
d) Yes, because deductive methods are present in every supervised machine learning algorithm as an element of controlling the training process.
✅ Answer: b) — Deductive methods remain relevant for encoding verified knowledge and feeding it into modern LLMs (e.g., LINC neurosymbolic theorem proving).
Q3. What is arc consistency in CSP and why is it used?
a) Arc consistency is the consistency of the path of connected variables in search and an element of partial solution representation.
b) Arc consistency guarantees that for any two variables connected by a constraint, their domains contain values that satisfy that constraint.
c) Arc consistency is a transformation of the problem, resulting in it consisting of n subproblems, in which the pairs are connected by a single arc.
d) Arc consistency is a partial order of pairs: variable-heuristic, accelerating solution finding.
✅ Answer: b) — Arc consistency ensures that for every constrained pair, valid domain values exist on both sides. It dynamically reduces effective domain sizes.
Q4. What is the partial order planning algorithm based on?
a) Hierarchically dividing the problem into areas of local subplans that are next combined.
b) The lack of distinction between actions that are generated for the same operators.
c) Utilising only the necessary constraints in the representation of the plan.
d) A partial order plan allows for conflicting sequences of actions, where conflicts are resolved later through additional searching.
✅ Answer: c) — Partial order planning uses only the minimally necessary ordering constraints, leaving actions unordered when order doesn't matter (least commitment principle).
Q5. What are the true properties of the evaluation function in algorithms for playing logical games?
a) The evaluation function must be consistent with the payoff function for terminal nodes and estimate it for all intermediate states.
b) It must return 0 for the terminal node of the game tree and be consistent with the payoff function for the others.
c) The evaluation function is a heuristic function for the cost of winning in one move.
d) The evaluation function is any linear function of the set of features describing the game state.
✅ Answer: a) — The evaluation function must agree with payoff at terminal nodes AND estimate it for all intermediate (non-terminal) states.
Q6. Why is it important for the heuristic to be admissible in state space search?
a) An admissible heuristic does not hide the problem and returns values no higher than the actual cost.
b) Because it allows for comparing values between nodes.
c) Because only an admissible heuristic defines equivalence classes of nodes based on its values.
d) Because it does not hide the path leading to a node that satisfies the goal test.
✅ Answer: a) — An admissible heuristic never overestimates the true cost → guarantees A* finds the optimal solution.
Q7. When do positions in the game tree become stable (quiescent)?
a) Stable (quiescent) positions are those for which there is a balance between attacking moves and moves that create threats.
b) Positions in the game tree become stable (quiescent) when their subtrees become balanced after applying alpha-beta pruning.
c) Stable (quiescent) positions are those for which the situation in the game does not correlate with significant changes in the value of the evaluation function over the next few moves.
d) Stable positions are below the depth that defines the horizon problem in the game tree.
✅ Answer: c) — Quiescent = "calm" states where the evaluation function won't change dramatically in the near future. Safe to stop search here.
Q8. How does constraint propagation affect the efficiency of a CSP-solving algorithm?
a) It is an alternative approach to backtracking search based on heuristic forward searching.
b) Constraint propagation shifts the search to the level of local operations within the variable domains.
c) Constraint propagation dynamically reduces the effective size of variable domains.
d) It breaks the problem into independent subproblems of constraint solving within individual pairs of variables.
✅ Answer: c) — Constraint propagation prunes domain values that cannot be part of any valid solution, shrinking the search space dynamically.
Q9. Do planning algorithms differ from heuristic state space search?
a) Planning algorithms are heuristic search algorithms based on a partial order graph heuristic.
b) Planning algorithms utilise knowledge from the symbolic representation of state change operators.
c) Planning algorithms do not build a complete transition graph from the initial state to the final state, but only a forest of partial graphs.
d) Planning algorithms build the action graph deterministically and later apply heuristics to linearise the partial order graph into the final graph.
✅ Answer: b) — Planning exploits the symbolic structure of operators (preconditions, effects) to guide search — this is what distinguishes it from pure heuristic search.
Q10. Why does unsupervised machine learning work and to what extent?
a) It transforms some attributes into decision classes based on correlation analysis.
b) It explores similarities between objects to make property transfers or determine equivalence classes.
c) It relies on augmentation of labelled data based on clustering.
d) It only works when clustering results correlate with an accepted class hierarchy.
✅ Answer: b) — Unsupervised learning discovers structure by measuring similarity, enabling clustering and property inference without labels.
Q11. What is the order of assigning attributes to the nodes of the decision tree?
a) Any order is acceptable as long as the attributes with the highest InfoGain value are chosen.
b) A single path contains a group of attributes determined by a clustering algorithm and then subjected to unsupervised attribute selection.
c) The assignment of attributes to nodes results from an unsupervised contextual assessment of cross-entropy.
d) The order in each path of the tree (root-to-leaf) results from the reduction of uncertainty.
✅ Answer: d) — Attributes are ordered by information gain (reduction of entropy/uncertainty), with the most informative attribute at the root.
Q12. What needs to be done to adapt decision trees to operate on numerical values?
a) It is necessary to quantize numerical attributes in a way statistically adjusted in terms of intervals for each attribute individually.
b) Functions should be introduced that assign appropriate symbols to numerical values from training data.
c) Numerical values that may appear in the input data can simply be treated as individual symbols.
d) Functions should be assigned to tree nodes that calculate the choice of the outgoing branch.
✅ Answer: a) — Numerical attributes must be discretized (binned) into intervals, with thresholds statistically chosen from training data per attribute.
Q13. How does training a neural network change it for specific tasks?
a) The network remains the same; only the structure is reorganized, including the positions of selected neurons, according to individual decision paths.
b) As a result of training, activation paths related to recognition of specific classes are created within the network during use.
c) Training causes the network parameters to adjust gradient-wise to a softmax probability distribution correlated with the given set of classes.
d) As a result of training, the connections between neurons are adjusted, and some may even be suppressed, due to changes in weights and the distribution of values generated at the outputs.
✅ Answer: d) — Training modifies connection weights; some connections are strengthened while others are weakened or effectively suppressed, tuning the network for the task.
Q14. What is the significance of document segmentation for the functioning of the RAG system?
a) Segmentation determines the detail of the response by defining the size of the text window as the basis for providing the answer. The size and method of segmenting text (fragments of documents) can facilitate the precise determination of the basis for generating a response.
b) Segmentation has no effect on response quality.
c) Segmentation does not affect response precision since the LLM generates independently, but it is crucial for processing efficiency.
d) Document segmentation facilitates generation of concise responses of limited length.
✅ Answer: a) — In RAG, segmentation size directly affects retrieval granularity and quality of evidence passed to the LLM. Smaller segments = more precise retrieval.
Q15. How does a neural network classify input data?
a) Each layer of the network defines the projection of input signals onto the set of classes, and at the end, the output layer performs aggregation and voting according to the softmax scheme.
b) The neural structures of a non-recurrent network form a forest of fuzzy classification trees built from subsets of neurons.
c) Activation functions shape the level of output signals, and in the output layer, signals from neurons are interpreted according to the assumed classification task.
