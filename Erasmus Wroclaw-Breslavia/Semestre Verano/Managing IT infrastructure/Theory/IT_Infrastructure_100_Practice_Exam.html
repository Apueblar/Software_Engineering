🖥️ Topic 01 — Windows Server Platform & Virtualization Foundational
1. Which type of hypervisor runs directly on the physical hardware without requiring a host operating system?
AType I (bare-metal)
BType II (hosted)
CContainerization
✅ A. Type I hypervisors (e.g. Hyper-V) run directly on the hardware with no host OS underneath; Type II runs as an application on top of a host OS.
2. What is the key difference between containers and virtual machines regarding the operating system?
AContainers each run a full independent guest OS, while VMs share one OS kernel
BContainers share a single OS kernel/image, while each VM requires its own full OS
CThere is no difference; both require a dedicated OS per instance
✅ B. Containers share the host's kernel and are far lighter weight; each VM carries its own complete guest operating system.
3. With Hyper-V enabled, how does a physical CPU core with Intel Hyperthreading appear to the hypervisor?
AAs a single physical core only
BAs two separate Logical Processors
CAs a virtual NUMA node assignment
✅ B. Hyperthreading exposes each physical core as two Logical Processors (LPs) to the hypervisor scheduler.
4. Which Windows Server installation method allows automated, network-based deployment to many computers without using physical media?
ADVD installation media
BUSB installation media
CWindows Deployment Services (WDS)
✅ C. WDS deploys images over the network (PXE boot) to many machines at once, removing the need for physical install media.

A512MB
B1024MB
C2GB
✅ A. Server Core can run on as little as 512MB RAM; 1024MB is needed only to perform the installation itself.

BPaaS
CIaaS

AStandard
BEssentials
CDatacenter
✅ C. Datacenter edition is licensed for unlimited OSEs, making it the choice for high-density virtualization hosts.
9. What is the primary distinction between a Role and a Feature in Windows Server?

CRoles and Features are interchangeable terms for the same concept

📁 Topic 04 — File and Folder Permissions NTFS
29. On which file systems are NTFS-style permissions available?
AFAT32 file systems only
BNTFS or ReFS file systems only
CFAT32 and NTFS, equally
✅ B. Granular ACL-based permissions are a feature of NTFS and ReFS; FAT32 has no concept of per-object security descriptors.
30. A folder has Everyone::Read::Deny and Everyone::Full Control::Allow both applied. What is the effective result for read access?
AFull Control applies, since Allow overrides Deny
BNo one can read it — even admins — since explicit Deny always wins
CThe permissions cancel out, leaving no access whatsoever
✅ B. Explicit Deny entries always take precedence over Allow entries in NTFS permission evaluation, regardless of scope.
31. Which statement correctly describes how permissions from a user account and their group memberships combine?
AOnly the most restrictive group's permissions apply
BPermissions are cumulative across the account and its groups
COnly the first matching group's permission is used
✅ B. NTFS Allow permissions are cumulative — a user's effective permission is the union of permissions from their account and every group they belong to.
32. An administrator wants a "drop" folder where users can upload files but cannot view or modify existing files. Which permission level is needed to achieve this?
ABasic permission levels only
BAdvanced (granular) permissions
CShare permissions only, NTFS default
✅ B. This write-only/drop-box behavior requires the granular advanced permissions (e.g. Create Files, no List/Read), not a basic permission level.
33. When permission inheritance is disabled on a folder, what choice is the administrator given for the previously inherited entries?
AEither delete them or convert them to direct (explicit) permissions
BThe folder automatically reverts to Everyone::Full Control
CInheritance settings can never be disabled at all
✅ A. Windows prompts to either remove the inherited entries entirely or copy/convert them into explicit permissions on the object.
34. When a file is copied from one NTFS folder to another (even on the same volume), what permissions does the copy receive?
AIt keeps the original file's direct permissions
BIt inherits permissions from the destination folder
CIt receives no permissions until manually configured
✅ B. A copy is treated as a brand-new object, so it always inherits the permissions of its new parent folder.
35. A file is moved within the same NTFS volume to a different folder. What happens to its permissions?
AIt inherits fully fresh permissions from the destination, like a copy
BDirect permissions stay; inherited ones now come from the new parent
CAll permissions are stripped and the file becomes inaccessible
✅ B. A same-volume move keeps the file's explicit permissions intact, while its inherited entries switch to those of the new parent.
36. A folder has NTFS permission G_Sales::Modify::Allow and Share permission Everyone::Full Control::Allow. Accessed remotely via its UNC path, what is the effective permission?
AFull Control, since Share permissions override NTFS
BModify, since the more restrictive permission wins
CFull Control, since NTFS permissions are ignored over the network
✅ B. When accessing over the network, Windows applies the most restrictive of the Share and NTFS permissions — here that is Modify.
37. What is Microsoft's recommended best practice for configuring Share vs. NTFS permissions on a shared folder?
ASet Share permissions very restrictively and leave NTFS open
BLeave Share wide open and control real access through NTFS
CApply identical restrictive permissions on both Share and NTFS for redundancy
✅ B. Best practice is to leave the Share permission wide open (Everyone:Full Control) and do all real access control via the more granular NTFS permissions.

47. In Windows configuration, which database underlies most Group Policy settings?

BThe Windows Registry
CThe SYSVOL share folder

BPreferences are enforced while Policies are merely suggested
CThere is no functional difference, only the name

49. A Local GPO can be scoped to apply separately to which of the following user categories?
AAdministrators, Non-administrators, or an individual user
BOnly Domain Admins, with no other targeting
COnly the current logged-on user, no other options

50. What are the two top-level components of a Group Policy Object?
ASoftware Settings and Security Settings
BUser Configuration and Computer Configuration
CLocal GPO and Domain-based GPO
✅ B. Every GPO is divided into the User Configuration and Computer Configuration nodes.
51. In the default GPO processing order, which level is applied first, and which is applied last (and therefore wins in a conflict)?
ALocal first, OU last (most specific wins)
BOU first, then Local applied last
CDomain first, then Site applied last
✅ A. GPOs apply in the order Local → Site → Domain → OU, so the OU-level GPO is processed last and wins any conflict.
52. What does RSoP (Resultant Set of Policy) represent?
AThe raw, unprocessed list of all GPOs linked anywhere in the forest
BThe final, effective settings after resolving inheritance and conflicts
CA report available only for software installation policies
✅ B. RSoP shows the net effective policy settings actually applied to a user/computer after all GPO inheritance and conflict resolution.
53. Which of the following setting types typically does NOT apply via the routine background refresh (every 90-120 minutes) and instead requires a restart or logoff?
AAdministrative Templates
BSecurity settings
CSoftware installation
✅ C. Software installation policies only apply at computer startup or user logon, not during the periodic background refresh cycle.

91. Which of the four core PKI security properties ensures that a sender cannot later deny having sent a signed message?
AConfidentiality
BIntegrity
CNon-repudiation
✅ C. Non-repudiation, provided by digital signatures, prevents a sender from later denying they sent a given message.
92. In a two-tier PKI hierarchy, why is the Root CA typically kept offline?
ATo minimize compromise risk, since its trust underpins the whole chain
BBecause Root CAs cannot issue certificates while online
CBecause offline CAs process certificate requests faster
✅ A. Since every certificate in the hierarchy ultimately traces trust back to the Root CA, keeping it offline drastically reduces its attack surface and compromise risk.
93. An administrator needs to recover a lost private key for a user whose disk failed. For which type of certificate can the CA's archived encrypted private key actually be recovered?

BEncryption certificates only (e.g., EFS)
CAny certificate type, without restriction
✅ B. Only encryption certificates (like EFS) are eligible for key archival/recovery; signing keys must remain solely with the original holder to preserve non-repudiation.
94. What is required to recover an archived private key from the CA's key archival store?
AA Key Recovery Agent (KRA) certificate
BThe user's domain password
CPhysical access to the Root CA server only
✅ A. A designated Key Recovery Agent, holding a KRA certificate, is required to decrypt and recover an archived private key.

BOnline Responder (OCSP)
CCA Web Enrollment portal
